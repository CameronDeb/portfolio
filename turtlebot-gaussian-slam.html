Online Gaussian Splatting SLAM on a TurtleBot 4

VSI Lab, University of Arizona · Poster at the Bay Area Robotics Symposium (BARS 2026), UC Berkeley, October 30, 2026

Cameron DeBough, Wonhee Koh, Eungjoo Lee

Code VSI Lab

Overview

Photorealistic 3D maps made with Gaussian splatting are usually built offline: record the images, run structure-from-motion (COLMAP or GLOMAP) to recover camera poses, then train the map. I wanted to know whether a robot could build that kind of map while it drives, and how it holds up against the offline approach on real hardware.

I ran MonoGS, an RGB-D Gaussian Splatting SLAM method from CVPR 2024, on a TurtleBot 4 (iRobot Create 3 base, Raspberry Pi 4, OAK-D Pro RGB-D camera, RPLIDAR) mapping an indoor room, and compared it with COLMAP + 3DGS and GLOMAP + 3DGS on the same recordings.

What I did

I led the project. Specifically, I:

  • Ran the robot experiments and recorded ROS 2 bags on the robot.
  • Built the pipeline that turns those bags into datasets, runs SLAM and structure-from-motion, and scores the results: trajectory accuracy (ATE with Umeyama alignment, using lidar SLAM from slam_toolbox as the reference) and rendering quality (PSNR, SSIM, LPIPS).
  • Tracked down a depth error in the OAK-D camera and corrected it using the lidar.
  • Prototyped a revisit planner that picks where the robot should go back to re-observe so the map improves.
  • Ran simulations in NVIDIA Isaac Sim.
  • Designed the poster.

Results

  • The depth camera reads long. The OAK-D depth was 11 to 13% too long. After modeling and correcting that error against the lidar, MonoGS tracking error (ATE) dropped from 7.4 cm to 1.2 cm.
  • Online mapping was faster. On a 1.8 m route, MonoGS mapped online in 2.4 min (31.0 dB PSNR). The offline pipelines took 6.8 min (COLMAP + 3DGS) and 4.0 min (GLOMAP + 3DGS, 29.7 dB PSNR), so mapping online was faster with comparable image quality.

Next

I'm extending this into a study, targeting IROS 2027, on when revisiting a spot actually improves an indoor Gaussian map when depth is unreliable and the robot can only travel so far.
